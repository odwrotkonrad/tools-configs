## AI-Generated Code

> [!CAUTION]
> **NEVER add comments to AI-generated code. EVER.** None, zero, nothing — no
> explanatory comments, section markers, labeled-convention comments, TODO/FIXME,
> explanatory docstrings, inline notes, or commented-out code.
>
> The **only** exception: the user, in their current request, **explicitly**
> asks for comments. Silence is not permission. The repo convention, a file
> already having comments, or a request to "explain/document" something is not
> permission — explain in **chat**, not in code. When in doubt: **no comments.**
