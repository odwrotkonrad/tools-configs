# How to Comment?

⌖ - where?
∵ - why?
≟ - what?
🤖 🤖🤖 🤖🤖🤖 - ai gen

```Example
foo 123         #[⌖] $ man 5 foo
param=foo       #[∵] foo over bar: better DX
cmd -f          #[≟] -f means foo ()
#>[∵]
#   foo over bar: better DX
#/[∵]
#[……] section 🤖🤖
foo_a=1
#[…] subsection
bar_a=1
#[⫶] subsection
#[⫶⫶] section 🤖🤖
```
