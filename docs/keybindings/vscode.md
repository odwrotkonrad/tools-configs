# VS Code Keybindings

Symbols: ⌥ alt · ⌘ cmd · ^ ctrl · ⇧ shift

## Cursor / Selection

⇞                PageUp                Cursor to top
⇟                PageDown            Cursor to bottom
⌘ ↑              Up 12 lines
⌘ ↓              Down 12 lines
⇧ ⌘ ↑            Select up 3 lines
⇧ ⌘ ↓            Select down 3 lines

## Editor

⌥ ⎋ / ⌥ Q        Close editor, focus first group
⌥ R              Reopen closed editor
⌥ ⇥              Next tab in group
⌥ 1              Focus first editor group
⌥ 2              Focus second editor group
⌥ ↓              Move lines down
⌥ ↑              Move lines up
⌥ F              Find in editor
⌥ R              Find / replace (find widget)
⌥ ]              Format document / selection
⌥ \              Toggle word wrap
⌥ M              Maximize editor group
⌥ B              Even editor widths
⌥ ⇧ L            Toggle advanced editing mode (line numbers, folding, sticky scroll)
⌥ ^ ←            Navigate left (grid-aware)
⌥ ^ →            Navigate right
⌥ ^ ↑            Navigate up / cycle aux-bar & side-bar views
⌥ ^ ↓            Navigate down / cycle aux-bar & side-bar views
⌥ L              Toggle command palette
F2               Rename opened file
⎋                Unmaximize editor group / close diff

## Search

⌥ W              Toggle quick text search
⌥ X              Toggle quick file open
⌥ S              Toggle search panel
⌥ G              Open search in editor / close search editor
⌥ R              Replace in files (search view)
⌥ ⎋ / ⌥ Q        Close search editor / panel
⏎                Re-run search / open result in group 2
↓                Search input → results / move down
↑                Move up in results
⎋                Search input → editor / results → input → first group

## Terminal

⌥ T              Create / focus / move terminal
⌥ F              Focus terminal find
⌥ ^ T            New terminal in focused group
⌥ ⎋ / ⌥ Q        Kill terminal editor / focus next group
⌥ ⇧ T            Open native console

## File Explorer

⌥ A              Toggle explorer
⎋                Reveal current file in explorer
⏎                Open file / toggle folder
⌥ ↑              Jump up 3 entries
⌥ ↓              Jump down 3 entries
F2               Rename file
⎋                Focus active editor group

## Output

⌥ ⎋ / ⌥ Q / ⎋    Close output panel

## Source Control

⌥ C              Toggle SCM aux bar
⌥ D              Toggle SCM Graph panel
⌥ /              Commit
⌥ ⇧ /            Commit amend
⌥ M              Generate commit message (in SCM input)
⌥ P              Push
⌥ ⇧ P            Force push (--force-with-lease)
↓                SCM message → changes list
⎋                Changes item → message input / message → editor

## Font Zoom

⌥ .              Zoom in (terminal / editor)
⌥ ,              Zoom out (terminal / editor)
⌥ 0              Reset zoom (terminal / editor)
⌘ 0              Reset window zoom
