## Git Workflow

Use the `ko`-git skills as the primary way to interact with git. Never hand-derive branch names, commit messages, or MR text.

- `/user-git-branch-name-upsert` — create/rename branch to a conventional name.
- `/user-git-commit` — commit with a generated message.
- `/user-git-mr-upsert` — create/update the MR/PR.
- `/user-git-upsert-all` — run all three in order.
