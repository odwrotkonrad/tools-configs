# Comments Convention

Label prefix `[symbol]`.

- `⌖` where · `≟` what · `∵` why
- `…` section start (named) · `⫶` section end (named) · repeat symbol to nest
- inline `#[≟] ...` · block `#>[∵]` … `#/[∵]` · unlabeled = ignore

Full spec & examples: [Commenting Convention](../../docs/readme/commenting-convention.md)
