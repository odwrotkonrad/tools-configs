# Comments Convention

Label prefix `[symbol]`.

- `⌖` where · `≟` what · `∵` why
- `…` section start (named) · `⫶` section end (named) · nest by symbol count, top level most symbols down to one innermost · section hugs its content (no blank line after introducer / before terminator; blanks between siblings ok)
- inline `#[≟] ...` · block `#>[∵]` … `#/[∵]` · unlabeled = ignore
- AI-generated: section named `🤖`, more 🤖 = wants more human review despite being AI-generated (🤖🤖🤖 a lot more · 🤖🤖 some more · 🤖 a little more); no mark = reviewed/trusted; default 🤖🤖, creator corrects
